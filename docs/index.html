Unlock Multi-Minute 4K YouTube Pre-Buffering on Any PC

My Quality 4k removes YouTube's hardcoded 35 MB (16-second) 4K SABR buffer cap to pre-load 1, 2, or 3 upcoming minutes of 2160p video while enforcing hardware-accelerated VP9 SDR decoding for entry-level and mid-range GPUs.

1. Core Engineering Architecture (v2.1.0)

512 MB SABR & Policy Unlocker

YouTube's internal base.js player caps 4K video buffers at 36,700,160 bytes (35 MB = 16.3s) and enforces a 15-second server-driven targetVideoReadaheadMs. My Quality 4k intercepts g.vWa policy objects and the SABR request coordinator to expand the video budget to 512 MB and continuously stream up to 60s, 120s, or 180s ahead.

Hardware Codec Enforcement (VP9 SDR)

Intercepts MediaSource.isTypeSupported and navigator.mediaCapabilities.decodingInfo to block software-heavy AV1 (av01) and 10-bit VP9 HDR (vp09.02), certifying 8-bit VP9 Profile 0 for smooth GPU hardware decoding.

30fps Limiter & Smart Drop Guard

Includes an optional 30fps stream filter (blocking framerate > 30) to cut GPU decode load in half on 4 GB VRAM cards, paired with an automatic Smart Drop Guard if frame loss exceeds 18%.

MSE Micro-Gap Stabilizer & Network Logs

Automatically bridges millisecond timestamp gaps in video.buffered to prevent infinite spinner stalls, while passively inspecting googlevideo.com/videoplayback chunks for live Mbps and latency telemetry.

2. Installation & Usage

  1. Download My-Quality-4k-v2.1.0.zip from GitHub Releases and extract the archive to a permanent folder.
  2. Open Google Chrome, Brave, or Edge and navigate to chrome://extensions/.
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked in the top-left corner and select the extracted folder containing manifest.json.
  5. Open any 4K YouTube video and click the Baby Blue Video Player extension icon to select your target resolution (2160p 4K) and pre-buffer horizon (60s, 120s, or 180s).

3. Local Telemetry Services (Node.js & Ruby)

The extension runs 100% standalone in the browser. For advanced CDN route diagnostics and statistical P50/P95 throughput reports, run the included local backend services: 

# Verify syntax across all extension and backend scripts
npm run verify

# Start the local Node.js HTTP telemetry server on http://localhost:3456
npm run telemetry:server

# Run the Ruby statistical route & cache analyzer
npm run telemetry:analyze
